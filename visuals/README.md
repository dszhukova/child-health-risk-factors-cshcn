# Power BI Dashboard

This folder contains a PNG preview of the Power BI dashboard created for my capstone project on child health risk factors and special health care needs.

## File

- `child_health_risk_factors_dashboard.png` — final dashboard overview

## Dashboard Purpose

The dashboard summarizes the main findings of the analysis, including:

- the distribution of children with and without special health care needs
- the relationship between accumulated risk factors and outcomes
- the most important individual and combined risk factors
- differences across selected demographic and family groups

The raw data and Power BI source file are not included in this repository.
